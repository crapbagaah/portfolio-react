## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/crapbagaah/portfolio-react.git
```

Navigate to the project:

```bash
cd portfolio-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open:

```text
http://localhost:3000
```
